# Jaypee Agentic AI International Summit (JAI 2026)

Official website for the **Jaypee Agentic AI International Summit (JAI 2026)** hosted at Jaypee Institute of Information Technology (JIIT), Wish Town Campus, Sector-128, Noida on **October 30 – 31, 2026**.

## 🚀 Tech Stack
- **React 18**
- **Vite 5**
- **Tailwind CSS**
- **Lucide React** (Vector Icons)

## 📌 Getting Started

### Prerequisites
- Node.js (v18+ recommended)
- npm

### Installation
```bash
git clone https://github.com/madhavgairola/jai-summit.git
cd jai-summit
npm install
```

### Development
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build
```bash
npm run build
```
Preview production build:
```bash
npm run preview
```
